# Yaseenis All-in-One

Tamil-first responsive Progressive Web App starter for a unified Yaseenis Islamic content platform.

## Included
- Mobile-first category home page and search
- Local-device favourites
- PWA manifest, service worker and icon
- Links to current Yaseenis website and files hub

## Current status
This is a starter interface, not yet a full synchronized content platform. Category links need to be checked against the actual live URLs. Universal search across all articles/PDFs/audio/video requires connecting authorized source feeds, exports, APIs or a shared content index. App Store / Play Store publishing is a later step and requires developer accounts and review.

## Hosting
Enable GitHub Pages for this repository (Settings → Pages → Deploy from branch → main / root). HTTPS is required for service workers and installation.
